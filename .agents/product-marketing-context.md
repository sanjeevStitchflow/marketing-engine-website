# Product Marketing Context

*Last updated: 2026-03-05*

## Product Overview
**One-liner:** CLI-first marketing engine that builds your entire marketing stack from the terminal using Claude Code.
**What it does:** Fork a GitHub repo, open it in Claude Code, and run interactive skills that produce blogs, case studies, sales decks, outbound campaigns, ICP lists, and explainer videos - all grounded in your actual positioning, voice, and messaging.
**Product category:** Marketing automation / AI-powered content engine
**Product type:** Open-source CLI tool (GitHub repo + Claude Code skills)
**Business model:** Open source repo. Requires Claude Code subscription. Optional paid API integrations (ElevenLabs, Apollo, Instantly).

## Target Audience
**Target companies:** Early-stage startups (Pre-seed to Series B), solo founders, small marketing teams
**Decision-makers:** Founders, CEOs, solo marketers, technical co-founders
**Primary use case:** Building a complete, consistent marketing stack without hiring an agency or dedicating a full-time marketer
**Jobs to be done:**
- Get from "I know my product" to "I have published marketing assets" fast
- Maintain consistent positioning across all channels
- Build marketing infrastructure that scales with the company
**Use cases:**
- Founder doing first marketing push before hiring
- Technical CEO who wants marketing in their workflow (terminal)
- Small team that needs full-stack marketing without full-stack headcount

## Problems & Pain Points
**Core problem:** Founders know their product deeply but can't translate that knowledge into consistent, high-quality marketing assets efficiently.
**Why alternatives fall short:**
- Agencies cost $10K+/month and still don't capture the founder's voice
- ChatGPT has no memory - every session starts from zero with generic output
- Freelancers need constant briefing and produce inconsistent work
- DIY takes weeks per asset with no system
**What it costs them:** Months of delayed marketing, inconsistent messaging, wasted spend on agencies that miss the mark
**Emotional tension:** Frustration of knowing exactly what to say but not having it written down. Guilt of neglecting marketing. Fear of sounding generic.

## Competitive Landscape
**Direct:** No direct competitor - unique positioning at intersection of CLI tools and marketing systems
**Secondary:** Marketing agencies, freelance copywriters - fall short because they don't capture founder voice and require extensive briefing
**Indirect:** ChatGPT/Claude chat, Jasper, Copy.ai - fall short because no persistent context, no system, no version control, no QA

## Differentiation
**Key differentiators:**
- Discovery-first: 15-question interview extracts real positioning before any content is created
- Persistent context: every skill builds on the same foundation (golden messaging, writing style, POV)
- Version-controlled: marketing assets live in git alongside code
- QA built in: approval gates prevent generic output from shipping
- Full stack: 8 skills cover blog to outbound to video in one system
**Why customers choose us:** It's the only tool that treats marketing like a codebase - systematic, version-controlled, and built on real founder input.
